👋 你的探索从这里开始

这是 explorations/<代号>/index.html 的起步模板。把它换成你的探索内容。

第一步：编辑同目录的 README.md（标题 / 思路 / 截图路径），看板会自动收录你的卡片。

你可以做什么

🎨 静态可视化

  • D3 / Chart.js / vis-network 画图
  • Mermaid 渲染流程
  • 纯 HTML/CSS 交互卡片

⚛ 用框架

  • Vite / Next / Astro / Vue / Svelte
  • build 后把产物放本目录
  • 确保 index.html 是入口

📝 设计稿

  • 纯 markdown 渲染的设计文档
  • 截图 + 注解
  • 线框图（Excalidraw 导出 SVG）

不要做的事

  • 调真实 API（前期纯静态，用 mock 数据展示思路）
  • 写到 /web 或其他同事目录（hook 会拦你）
  • 提交大于 200KB 的图片到仓库

提交

git add explorations/<代号>
git commit -m "[pair] 阶段性探索：<一句话>"
git push

push 到 main 后，CI 30-60 秒内会刷新看板「前期探索」tab。
